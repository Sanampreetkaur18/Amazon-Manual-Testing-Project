# Amazon-Manual-Testing-Project

Project Overview

This project demonstrates a comprehensive manual testing process for the Amazon website, following professional QA practices. The objective was to ensure critical functionalities of the application work as expected and to document the testing workflow from planning to defect reporting.

Key Objectives:

Understand application functionality and requirements

Develop test plans, scenarios, and detailed test cases

Execute test cases and log defects accurately

Maintain traceability between requirements, test cases, and defects

Project Scope

Tested Features: User Login, Product Search, Add to Cart, Checkout, Account Management

Testing Type: Manual Testing

Tools Used: Jira, Zephyr, GitHub

Platform: Google Chrome (Desktop)

Project Artifacts

Test Plan: Defines the testing approach, objectives, scope, resources, and schedule.

Test Scenarios: High-level scenarios derived from application functionality.

Test Cases:  Step-by-step test instructions with expected outcomes.

Test Execution Report:  Captures results of test execution (Pass/Fail).

Defect / Bug Report:  Includes all identified defects with screenshots, severity, and priority.

Traceability Matrix (RTM):  Maps requirements to test cases and defects to ensure complete coverage.

Project Highlights

Successfully executed all planned test cases and validated application functionality

Logged and tracked defects, including evidence and proper documentation

Maintained complete traceability between requirements, test cases, execution results, and defects

Demonstrates end-to-end manual testing workflow aligned with QA best practices
